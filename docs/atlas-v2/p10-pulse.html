P10 — Product Pulse

Product Pulserapid:p10-pulseArc 3 · Compoundcomposed
Post-ship, produces a time-windowed usage / performance / error / feedback report that feeds the next build's P0 — closing the compound loop.
Fixed vs. Dynamic
FixedThe report format; the pulse → vision loop.
DynamicThe data sources (analytics, error tracking, logs) for this product.
Files touched
readsanalytics · errors · logs
writesdocs/pulse-reports/YYYY-MM-DD.md
Example
A weekly pulse note in docs/pulse-reports/ surfaces the top error and the least-used feature — which become inputs to the next build's pillars.
Why it's valuable
The loop is the product. Each build's pulse makes the next build start smarter; a single build is just an artifact.
